# Customizing Reading Now

The **Reading Now** screen is organized into sections. You can choose which sections show up, their order, and a few related behaviors from **Settings → Reading Now**.

## Sections

| Section | Can be reordered | Can be turned off |
|---|---|---|
| **Recent** | No — always first | No — always on |
| **Next Up** | Yes | Yes |
| **Pick Up Where You Left Off** | Yes | Yes |
| **Finished** | Yes | Yes |

Tap **Edit** in the Reading Now settings screen to drag sections into a new order or toggle them off with the switch that appears next to each one.

## Other Reading Now Options

- **Only show titles on this device** — hides items that were opened on a different device
- **Hide locked titles** — keeps titles from locked collections out of Reading Now entirely
- **Automatically restore current reading session** — reopens the book/page you were on when you last quit the app
