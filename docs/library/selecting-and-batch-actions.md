# Selecting Books & Batch Actions

Tap **Select** in the library header to enter selection mode.

## Selection Mode Basics

- Tap books to add/remove them from the selection
- **Select All / Deselect All** toggles in the header
- **Done** exits selection mode
- A selection toolbar appears docked at the bottom of the screen with quick actions and a **⋯** menu for everything else

## Quick Actions

| Action | Icon |
|---|---|
| Duplicate | doc.on.doc |
| Share | square.and.arrow.up (opens the system share sheet) |
| Delete | trash |

## The ⋯ Menu (More Actions)

| Action | What it does |
|---|---|
| **Mark as read / Mark as unread** | Toggles read status for every selected book |
| **Set reading direction** | Applies Left‑to‑Right or Right‑to‑Left to all selected books at once |
| **Batch rename files** | Renames every selected file using one base name you type (e.g. "Chapter" → Chapter 1, Chapter 2, …) |
| **Remove lock** | Removes the lock from any locked collections the selected items belong to |
| **New collection from selection** | Creates a new collection containing exactly the selected books |
| **Copy** | Duplicates the selected books in place |
| **Move** | Moves the selected books into a different collection |

## Single-Book Context Menu

Long‑press an individual book (outside selection mode) for a shorter menu: **Open**, **Favorite / Unfavorite**, and **Delete**.
