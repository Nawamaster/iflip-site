# Search

Open the **Search** tab (iPhone) or sidebar item (iPad) to search your entire library at once, across all collections.

## What Gets Searched

Typing a query matches against:
- Book title
- File name
- File format (e.g. "pdf", "cbz")
- Collection name

Results are sorted by most recently opened first.

## Using Results

- Results display in the same **Grid** or **List** mode as your library
- Tap a result to jump straight into the reader
- Long‑press (or use the context menu) for **Open** or **Delete**
- An empty query shows a placeholder illustration; a query with no matches shows a "No Results" message suggesting you try a different title, filename, format, or collection name
