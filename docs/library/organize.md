# Organizing Your Library

iFlip gives you several tools to keep your library tidy and easy to navigate. Your library lives under **On My iPhone** (or **On My iPad**), reached from the tab bar / sidebar.

## Collections

Group your files into collections (e.g. Manga, Comics, Novels). Collections appear as cards in a grid — 3 columns on iPhone, an adaptive multi-column grid (200–240pt cells) on iPad.

- Create a new one with the **folder.badge.plus** button in the library header
- Tap a collection to open the books inside it
- Tap **Select** in the header, or long-press a collection, to see all collection-level actions — see [Collections](./collections.md)
- Switch between **Grid** and **List** view from the **⋯** menu in the header

## Favorites

Mark your favorite books or collections for quick access.

- On a book: long‑press for the context menu → **Favorite** (there's no always-visible star icon on the cover — it's context-menu only)
- On a collection: long‑press → **Favorite**
- View everything you've starred from the **Favorites** tab / sidebar item

## Sorting

Sort your library from the **⋯** menu in the header:
- **Title** — alphabetical order
- **Recent** — last opened
- **Format** — grouped by file format

## Grid vs. List

Switch the library display mode from the **⋯** menu → **View**:
- **Grid** — cover art tiles
- **List** — compact rows with title, format, and size

## iPhone vs. iPad Layout

- **iPhone**: header shows the collection title and a **⋯** menu; the collections grid is 2 columns, and inside a collection the header reads "‹ On My iPhone"
- **iPad**: the sidebar stays visible (or can be collapsed with the sidebar icon); a large title and icon buttons (Add Collection, Select) sit at the top of the content area, with a "‹" circular back button when inside a collection

## Reading Now

The **Reading Now** tab/sidebar item shows your recently opened books grouped into sections (Recent, Next Up, Pick Up Where You Left Off, Finished). You can customize which sections appear and their order — see [Reading Now Settings](./reading-now.md).
