# Managing Collections

Long‑press (or use **Select** then the **⋯** menu) on a collection card to see the full set of actions.

## Collection Actions

| Action | What it does |
|---|---|
| **Favorite / Unfavorite** | Adds or removes the collection from Favorites |
| **Mark As Read / Unread** | Marks every title in the collection as read or unread |
| **Rename** | Renames the collection (also updates the on-disk folder) |
| **Lock / Unlock** | Hides the collection's contents behind Face ID / Touch ID / device passcode |
| **Copy** | Duplicates the entire collection, including its files, under a new name |
| **Show Info** | Opens a summary sheet: title count, total size, and a breakdown by file format |
| **Show In Files** | Opens the Files app at the folder where this collection's files are stored |
| **Delete** | Removes the collection and all of its files from the library (with a confirmation prompt) |

## Locking a Collection

Locking asks for Face ID, Touch ID, or your device passcode the first time you try to unlock it again — iFlip does not have a separate collection‑lock passcode; it uses the same on-device authentication as unlocking your phone. See [Privacy & Locked Content](../settings/privacy-and-locked-content.md) for the related app‑level passcode/Face ID setting that governs age‑restricted content.

## New Collection

Tap the **folder.badge.plus** icon in the library header (or during import) to create a new, empty collection by name.
