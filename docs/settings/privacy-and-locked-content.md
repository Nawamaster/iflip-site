# Privacy & Locked Content

iFlip can hide sensitive collections behind a passcode and/or Face ID.

## Setting Up a Passcode

1. Go to **Settings → Password**
2. Tap **Create Passcode**
3. Enter and confirm a passcode (at least 4 characters)

Once set, you can:
- **Change Passcode…** to set a new one
- **Remove Passcode** to turn locking off entirely (this also disables Face ID and requires confirmation)

## Face ID

With a passcode in place, toggle **Use Face ID** to unlock locked content with Face ID instead of typing your passcode each time.

> iFlip's own guidance: Face ID can bypass your passcode, so only enable it if you're the only person enrolled in Face ID on this device.

## Locking a Collection

The passcode/Face ID you set up here is what's checked whenever you **lock a collection** from the library (long‑press a collection → **Lock**). See [Managing Collections](../library/collections.md) for how to lock/unlock a specific collection, and [Reading Now](../library/reading-now.md) for hiding locked titles from your Reading Now feed.

## Age & Content Rating

Content in iFlip can be tagged with an age rating (**All Ages**, **12+**, **16+**). Setting your **visible content rating** hides higher-rated comics from view; this pairs with the passcode above for an extra layer of protection.
