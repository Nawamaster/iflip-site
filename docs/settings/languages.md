# Languages

**Settings → Languages** shows the app's current display language. iFlip's interface is currently English-only — there's no in-app language switcher yet.

If you notice text that could be clearer, or you find an error, use **Give Translation Feedback** on this screen to let the developer know, ideally with a screenshot attached.

> **Content Languages** (a separate, per-library filter for the language of your comics/books) may appear in a future update; it isn't reachable from the Settings screen yet.
