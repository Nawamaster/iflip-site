# Manage Space

**Settings → Manage Space** shows how much storage your library is using and gives you tools to clean it up.

## Storage Overview

- A bar breaks down space used by **Other apps**, **iFlip's library**, and **Free** space on your device
- **On My iPhone/iPad** shows the total size of everything currently imported

## Cleanup Actions

| Action | Effect |
|---|---|
| **Rebuild thumbnails** | Regenerates cover thumbnails the next time they're displayed |
| **Clear cache** | Removes temporary cache files only — imported library files are untouched |
| **Empty library** | Removes **all imported files** from this device |
| **Clear reading progress** | Resets every book's current page/progress and clears Reading Now history |
| **Delete all content and settings** | Full reset — removes all files *and* every app setting. This cannot be undone. |

Each destructive action shows a confirmation dialog before it runs, and a short status message afterward (e.g. "Cleared 45 MB of cache.").

> **Tip:** If you just want to free up space without losing your reading history, use **Clear cache** first — it's the only non-destructive option in this list.
