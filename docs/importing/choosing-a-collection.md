# Choosing a Collection While Importing

Whenever you import files (from Files, iCloud Drive, or Google Drive), iFlip asks which collection to file them into.

## How It Works

1. After picking files, a collection picker sheet appears showing your existing collections as a 3‑column grid, each labeled with its name and title count
2. Tap a collection to drill into it and preview the books already inside — swipe back or tap the back arrow to return to the grid
3. A button fixed at the bottom of the sheet never moves while you browse, and its label changes with context:
   - At the root grid: **"Add to Library"** — imports into your first/default collection
   - Inside a specific collection: **Add to `"Collection Name"`**
4. Tap **folder.badge.plus** in the top-right corner to create a brand-new collection on the spot and import straight into it
5. Tap **Cancel** to discard the pending files and close the sheet without importing

The sheet always opens at a large, fixed height so collection names aren't cut off.
