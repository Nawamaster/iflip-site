# Import from Google Drive (Web Drive)

## How to Connect

1. **iPhone**: go to the **Library** tab → **Web Drive**; **iPad**: select **Web Drive** in the sidebar (or go to **Settings → Web Drive → Google Drive → Sign in**)
2. Tap **Sign in with Google** and complete the Google sign-in flow
3. Choose a folder in your Drive — only one folder can be selected, and subfolders inside it aren't shown
4. Browse the files in that folder
5. Select the files you want and tap **Download** to copy them into iFlip

## Notes

- Files are downloaded and saved into your local iFlip library, inside a collection named **"Web Drive"**
- This is a manual import — not a real-time sync; later changes in Drive won't be reflected automatically
- A **Drive Log** view is available from the Web Drive screen showing recent Drive activity (folder loads, downloads, errors) — useful if a download seems stuck
- You can disconnect Google Drive at any time from **Settings → Web Drive** or **Settings → Web Drive → Manage your accounts**, by tapping **Sign Out** / **Logout**
- Signing out does not delete files you already imported
