# Import from Files App

The most direct way to add content to iFlip is from the Files app (or any storage provider hooked into it) on your iPhone or iPad.

## How to Import

1. Open **iFlip Reader**
2. Go to the **Library** tab (iPhone) or tap **Import from Files** in the sidebar hub (iPad)
3. Tap **Import Files** — the system file picker opens
4. Select one or more supported files
5. Choose a collection for them — see [Choosing a Collection](./choosing-a-collection.md)
6. The files are copied into your library and a confirmation message appears (e.g. "3 files added")

## Supported Locations

The file picker can browse anywhere the Files app can reach, including:
- On My iPhone / iPad
- iCloud Drive
- Third‑party cloud storage apps (Dropbox, OneDrive, etc., if installed)

## Supported Formats

PDF, EPUB, CBZ, CBR, CB7, CBT, ZIP, 7Z, TAR, TXT, Markdown, CSV, JPG/JPEG, PNG, GIF, WebP, HEIC/HEIF, TIFF, BMP.

## Duplicate Handling

If a file with the same name already exists in the destination collection, iFlip automatically skips it during import and tells you how many files were skipped (e.g. "2 files added. 1 already in library."). Duplicate files already in your library are also cleaned up automatically the next time the app starts.

## Rescan for New Files

If you copy files into iFlip's library folder outside of the app (for example with a computer or a file manager), use **Settings → ⋯ menu → Scan Content** from the Library screen to pick them up without a full re-import.
