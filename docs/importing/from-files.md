# Import from Files App

The easiest way to add content to iFlip is directly from the Files app on your iPhone or iPad.

## How to Import

1. Open **iFlip Reader**
2. Go to **Library** tab
3. Tap **Import from Files**
4. Browse to your file and tap it
5. The file is added to your library automatically

## Supported Locations

You can import from any location available in the Files app:
- On My iPhone / iPad
- iCloud Drive
- Third-party cloud storage apps
