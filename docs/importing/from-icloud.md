# Import from iCloud Drive

Connect your iCloud Drive to browse and import files directly into iFlip.

## How to Connect

1. Go to **Library** tab
2. Tap **Cloud** → **iCloud Drive**
3. Browse your iCloud folders
4. Tap any supported file to import it

## Notes

- Files are copied into iFlip's local library
- This is an import (copy), not a sync — changes in iCloud Drive won't automatically update in iFlip
