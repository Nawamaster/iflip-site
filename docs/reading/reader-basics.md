# Reader Basics

iFlip provides a clean, distraction-free reading experience for all supported file types.

## Opening a Book

Tap any book in your library to open it. The reader opens automatically based on the file type.

## Navigation

| Action | Result |
|--------|--------|
| Tap left side | Previous page |
| Tap center | Show / hide menu |
| Tap right side | Next page |
| Pinch | Zoom in / out |
| Swipe left/right | Turn page |

## Reader Menu

Tap the **center of the screen** to show the menu:

- **Top bar** — Back button, bookmark, spread mode, reading direction, settings
- **Bottom bar** — Page slider, page number, thumbnail strip

## Reading Direction

For manga (right-to-left), tap the **RTL button** in the top bar to switch reading direction.
